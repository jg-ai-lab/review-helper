# 엑셀 납품 연습 · 가상 꽃집 3개월 주문 합치기

서비스 B의 **정리+요약 패키지(40,000원·3일)** 주문이 들어왔다고 가정하고 처음부터 끝까지 한 번 해 보는 연습입니다. 모든 가게·고객 정보는 가상입니다. 이 폴더는 GitHub Pages 공개 대상이 아닙니다.

## 가상 주문 내용

> 안녕하세요. 작은 꽃집을 하고 있는데 8월부터 10월까지 주문을 달마다 다른 파일에 적어 왔어요. 적는 사람이 바뀌어서 형식이 제각각입니다. 세 파일을 하나로 합치고 월별·상품별 매출을 한눈에 보고 싶어요. 가격표는 장미 꽃다발 35,000원, 프리지아 꽃다발 25,000원, 꽃바구니 50,000원, 몬스테라 화분 30,000원입니다.

받은 파일: `2026-08_주문.xlsx`, `2026-09_주문.xlsx`, `2026-10_주문.xlsx`

## 순서

1. **시간 재기 시작.** 실제 주문이라면 3일 안에 끝나야 합니다. 걸린 시간을 적어 두면 가격이 적절한지 판단할 수 있어요.
2. **원본은 건드리지 않기.** 사본을 만들어 작업합니다.
3. **파일 훑어보기 (15분).** 열 이름·순서, 제목 행, 날짜 형식, 이상한 값을 메모합니다. 실제 주문이라면 이 단계에서 [`MESSAGES.md`](../../MESSAGES.md)의 "자료 확인 후 범위 안내"를 보냅니다.
4. **정리하기.** 엑셀 수식으로 해도 되고 [`samples/excel/clean_sales.py`](../../samples/excel/clean_sales.py)를 고쳐 써도 됩니다.
5. **결과 파일 만들기.** 시트 3개:
   - `정리된 주문` — 날짜·고객명·연락처·상품·수량·금액·결제 열로 통일
   - `월별 상품 요약` — 월 × 상품 수량·매출, 합계
   - `확인 필요` — 원본 파일·행 번호·문제·처리한 방법
6. **사장님께 물어볼 것 정리.** 임의로 판단한 부분은 질문으로 남깁니다.
7. **납품 메시지 쓰기.** [`MESSAGES.md`](../../MESSAGES.md)의 "납품" 템플릿을 채워 봅니다.
8. **채점.** 끝난 다음에만 [`ANSWER.md`](ANSWER.md)를 열어 행 수와 합계를 맞춰 봅니다.
