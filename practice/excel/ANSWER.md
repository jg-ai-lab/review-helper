# 정답지 · 먼저 보지 마세요

`make_practice.py`가 자동으로 만든 파일입니다. 직접 정리를 끝낸 뒤 결과를 맞춰 보세요.

## 심어 둔 문제

| 파일 | 행 | 구분 | 처리 기준 |
| --- | --- | --- | --- |
| 8월 | 9 | 중복 행 | 바로 윗 행과 같음 → 제외 |
| 8월 | 14 | 금액 오타 | 350,000원 → 단가×수량 35,000원 |
| 8월 | 19 | 합계 행 | 데이터가 아님 → 제외 |
| 9월 | 8 | 수량 빈칸 | 금액÷단가로 1개 추정 가능 → 반영하되 확인 필요로 표시 |
| 9월 | 13 | 이름 빈칸 | 전화번호로 같은 고객 확인 가능 → 확인 필요로 표시 |
| 10월 | 5 | 다른 파일과 중복 | 9월 파일 마지막 주문(9/30)과 같음 → 제외 |
| 10월 | 7 | 빈 행 | 제외 |
| 10월 | 12 | 취소(음수) | 환불로 보고 합계에서 차감, 확인 필요로 표시 |
| 10월 | 15 | 빈 행 | 제외 |
| 10월 | 19 | 알 수 없는 상품 | 가격표에 없음 → 합계에서 빼고 사장님께 질문 |
| 10월 | A열 전체 | 날짜가 숫자 | 엑셀 날짜 일련번호(예: 46296) → 날짜 형식으로 변환 |

공통: 연락처는 `010-0000-XXXX`로, 상품명은 가격표 이름으로, 결제는 카드·현금·계좌이체로 통일합니다.
