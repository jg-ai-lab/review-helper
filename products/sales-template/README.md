# 작은 가게 월 매출 정리 · 엑셀 템플릿 (시제품)

판매용 디지털 상품 시제품입니다. 아직 어디에도 올리지 않았습니다.

- `월매출정리_템플릿.xlsx` — 판매할 빈 템플릿
- `월매출정리_예시.xlsx` — 가상 카페 1~10월 매출이 들어간 예시 (상품 이미지·미리보기용)
- `preview/preview-01~03.png` — 판매 페이지용 미리보기 (매출입력, 월별 요약, 연간 그래프). 템플릿 화면을 HTML로 다시 그린 것이며 숫자는 예시 파일과 같음
- `render_preview.py` — 미리보기 이미지를 다시 만드는 스크립트 (`marketing/kmong/render_details.py`의 스타일·Edge 캡처 재사용)
- `make_template.py` — 두 파일을 다시 만드는 스크립트 (`.venv\Scripts\python.exe products\sales-template\make_template.py`)

## 구성

| 시트 | 내용 |
| --- | --- |
| 사용법 | 3단계 사용 안내, 환불·가격 변경 처리법 |
| 품목 | 상품명·단가 최대 30개 |
| 매출입력 | 날짜·품목·수량·결제를 입력하면 단가·금액 자동 계산 (1,000행, 품목·결제는 목록 선택) |
| 월별 요약 | 연도·월을 넣으면 품목별 수량·매출, 결제별 매출, 그해 1~12월 매출 표와 막대그래프 |

매크로 없이 수식만 씁니다. 2026-11-01 엑셀에서 다시 계산해 확인한 값: 예시 10월 매출 767,000원(품목별 합계와 결제별 합계 일치), 1~10월 월별 매출 모두 Python 계산값과 일치, 오류 셀 없음. 구글 시트·한셀에서는 아직 열어 보지 않았습니다.
