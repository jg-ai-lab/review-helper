# 로컬 LLM 데모 · 사내 규정 도우미 (서비스 D)

인터넷 없이 이 PC에서만 도는 문서 질문 답변(RAG) 데모입니다. 문서는 모두 직접 쓴 가상 회사 '샘플테크'의 규정 20개(`docs/`)입니다.

## 구성

- 모델: Ollama의 `qwen3:8b`(답변, Apache-2.0)와 `bge-m3`(문서 검색용 임베딩, MIT). 쓰기 전에 각 모델 페이지에서 현재 라이선스를 다시 확인합니다.
- `app.py`: 외부 패키지 없이 Python 표준 라이브러리만 사용. Ollama(`127.0.0.1:11434`)만 호출합니다.
- 답변마다 근거 문서를 펼쳐 볼 수 있고, 문서에 없는 질문에는 "찾지 못했습니다"라고 답하게 했습니다.

## 실행

```powershell
ollama pull qwen3:8b
ollama pull bge-m3
.venv\Scripts\python.exe products\local-llm-demo\app.py index
.venv\Scripts\python.exe products\local-llm-demo\app.py serve
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. 터미널에서 한 번만 물어보려면 `app.py ask "질문"`을 씁니다.

## 확인 질문

`check.py`가 아래 질문을 차례로 던지고 답에 정답 숫자·문서가 들어 있는지 확인합니다.

| 질문 | 기대하는 답 | 근거 문서 |
| --- | --- | --- |
| 배우자 출산 휴가는 며칠이에요? | 10일 | 04_경조사 |
| 서울 출장 숙박비 한도는? | 10만 원 | 05_출장비 |
| 비밀번호를 몇 번 틀리면 잠겨요? | 5번 | 09_비밀번호 |
| 교육비 지원받고 6개월 만에 퇴사하면? | 50% 반환 | 12_교육비지원 |
| 회의실은 한 번에 몇 시간까지 예약돼요? | 2시간 | 16_회의실 |
| 구입 8개월 된 제품 고장 A/S는 무료인가요? | 무상 수리 | 20_AS접수 |
| 회사 주차 지원금은 얼마예요? (문서에 없음) | 찾지 못함 | 없음 |

## 점검 결과 (2026-11-01, RTX 4070 Ti 12GB)

- 추론 모드 끔: 6/7 통과, 답변당 약 0.5~2초. "서울 출장 숙박비"에서 괄호 속 예외(서울·부산·제주 10만 원)를 놓치고 8만 원이라고 답함. 프롬프트에 예외 조건 확인 지시를 넣어도 같음.
- 추론 모드 켬(`THINK = True`, 기본값): 7/7 통과, 답변당 약 2~3초. 첫 질문은 모델을 불러오느라 더 걸림.
- 고객 납품 시에는 고객 문서로 확인 질문 20개 이상을 만들어 같은 방식으로 점검하고 결과표를 함께 냅니다.
