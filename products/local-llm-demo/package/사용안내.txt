사내 AI 비서 사용 안내
========================

이 프로그램은 회사 PC 한 대에서만 동작합니다. 질문과 문서는 인터넷으로 나가지 않습니다.
(처음 설치할 때만 프로그램과 AI 모델을 내려받기 위해 인터넷이 필요합니다.)


1. 처음 설치 (한 번만)
----------------------
1) 받은 zip 파일을 오른쪽 클릭 → [속성] → 아래쪽 [차단 해제]에 체크 → [확인]을 누릅니다.
   (이렇게 하면 압축을 푼 파일마다 뜨는 보안 경고가 대부분 사라집니다. [차단 해제]가 없으면 넘어갑니다.)
2) zip을 풀고, 폴더를 원하는 위치(예: C:\사내AI비서)에 통째로 복사합니다.
   바탕 화면이나 OneDrive 폴더보다 C 드라이브 아래 폴더를 권장합니다.
3) '설치.bat'을 더블클릭합니다. 검은 창에 아래 4단계가 차례로 나옵니다.
   [1/4] Ollama 확인   : AI 실행 프로그램 Ollama가 없으면 자동으로 설치합니다(1~3분).
                         "이 앱이 디바이스를 변경하도록 허용" 창이 뜨면 [예]를 누릅니다.
   [2/4] Ollama 실행   : Ollama를 켭니다. 작업 표시줄 오른쪽 아래에 라마 그림이 생깁니다.
   [3/4] 모델 선택     : 그래픽카드 메모리에 맞는 AI 모델을 고릅니다.
   [4/4] 모델 다운로드 : 문서 검색 모델과 답변 모델을 내려받습니다. 수 GB라 10~30분 걸릴 수 있습니다.
4) 설치가 끝나면 브라우저에 채팅 화면이 열립니다.

Ollama 자동 설치가 안 될 때 (검은 창에 "winget이 없어..." 또는 "설치를 확인하지 못했습니다"가 나올 때)
  1) 브라우저에서 https://ollama.com/download 를 열고 [Download for Windows]를 누릅니다.
  2) 내려받은 OllamaSetup.exe를 실행하고 [Install]을 누릅니다.
  3) 설치가 끝나면 PC를 한 번 다시 시작한 뒤 '설치.bat'을 다시 더블클릭합니다.
     (Ollama가 이미 있으면 [1/4]를 건너뛰고 모델 다운로드부터 이어서 합니다.)


2. 보안 경고가 뜰 때
--------------------
이 프로그램은 개인이 만든 프로그램이라 Microsoft 인증서(코드 서명)가 없습니다.
그래서 처음 실행할 때 Windows나 백신이 "알 수 없는 프로그램"으로 경고할 수 있습니다.
프로그램은 이 PC의 Ollama(127.0.0.1)에만 연결하고, 인터넷으로 자료를 보내지 않습니다.

- "Windows의 PC 보호" 파란 창 (SmartScreen)
  창 안의 [추가 정보]를 누르면 [실행] 버튼이 나옵니다. [실행]을 누릅니다.
  '설치.bat'과 '사내AI비서.exe' 각각 처음 한 번만 뜹니다.

- '사내AI비서.exe'가 사라졌거나 "위협이 검색됨" 알림이 뜸 (Windows 보안·Defender)
  1) 시작 → [Windows 보안] → [바이러스 및 위협 방지] → [보호 기록]을 엽니다.
  2) '사내AI비서.exe' 항목을 누르고 [작업] → [복원]을 누릅니다.
  3) 다시 지워지지 않게 하려면 같은 화면의 [설정 관리] → [제외 추가 또는 제거] → [제외 사항 추가]
     → [폴더]에서 이 프로그램 폴더(예: C:\사내AI비서)를 고릅니다.

- V3·알약 등 다른 백신이 막을 때
  백신의 [검역소] 또는 [치료함]에서 '사내AI비서.exe'를 [복원]하고, [예외 설정]에 이 프로그램 폴더를 추가합니다.

- 회사 보안 정책(관리자 계정, 보안 프로그램) 때문에 실행이 안 되면 사내 전산 담당자에게
  이 안내서와 프로그램 폴더 위치를 함께 전달해 주세요. 그래도 안 되면 크몽 메시지로 알려 주세요.


3. 매일 쓰는 법
---------------
1) '사내AI비서.exe'를 더블클릭합니다. 검은 창이 뜨고 브라우저가 열립니다.
2) 브라우저에서 질문합니다. 답 아래 [근거 문서]를 눌러 원문을 확인할 수 있습니다.
3) 다 쓰면 검은 창을 닫습니다.
   주소창에 http://127.0.0.1:8765 를 입력해도 같은 화면이 열립니다(검은 창이 켜져 있을 때).


4. 회사 문서 넣기·바꾸기
------------------------
1) 채팅 화면 위쪽 [문서 관리 (올리기·빼기)]를 누릅니다.
2) 점선 칸에 파일을 끌어 놓거나, 점선 칸을 눌러 파일을 고릅니다(여러 개 가능).
   "올렸습니다. 이제 질문할 수 있어요."가 나오면 바로 질문할 수 있습니다.
   - 읽을 수 있는 형식: PDF(.pdf), 텍스트(.txt), 마크다운(.md). 파일 하나에 50MB까지.
   - 한글(.hwp)·워드·엑셀 문서는 [파일] → [다른 이름으로 저장]에서 PDF로 저장해 올려 주세요.
   - 스캔한 그림 PDF는 글자를 읽지 못합니다. 목록에 "글자를 읽지 못함"이 보이면 빼 주세요.
   - 같은 이름의 파일을 올리면 새 내용으로 바뀝니다.
3) 샘플 문서나 필요 없는 문서는 목록 오른쪽 [빼기]를 누릅니다.
   지워지지 않고 프로그램 폴더의 '뺀 문서' 폴더로 옮겨집니다.
4) 'docs' 폴더에 직접 파일을 넣거나 지워도 됩니다. 이때는 '사내AI비서.exe'를 다시 실행하면
   바뀐 문서를 자동으로 다시 읽습니다.
5) 'config.json'을 메모장으로 열어 회사 이름(company)과 문의처(contact)를 바꿀 수 있습니다.


5. 답변 점검 (확인 질문 결과표)
------------------------------
문서를 바꾼 뒤나 한 달에 한 번, AI가 회사 규정을 맞게 답하는지 한 번에 확인합니다.
1) 채팅 화면의 [답변 점검 (확인 질문 결과표)]를 누릅니다.
2) 한 줄에 하나씩 "질문 | 답에 들어가야 할 말"로 적습니다.
   예) 연차는 1년에 며칠이에요? | 15일
   - 들어가야 할 말이 여러 개면 / 로 나눕니다.  예) 출장 숙박비는? | 서울 / 10만
   - 문서에 없는 질문은 (없음)이라고 적습니다. "찾지 못했습니다"라고 답하면 통과입니다.
   - 회사 규정에서 자주 묻는 질문 20개 이상을 권장합니다. [질문 저장]을 누르면 '확인질문.txt'에 저장됩니다.
3) [모두 실행]을 누르면 질문마다 통과·실패가 표로 나옵니다.
4) 결과표는 프로그램 폴더의 '점검결과' 폴더에 CSV(엑셀에서 열림)로 저장됩니다.
   월 관리를 신청하셨다면 이 파일을 크몽 메시지로 보내 주세요. 실패한 질문의 원인을 찾아 설정을 고쳐 드립니다.
   - 기본으로는 질문·통과 여부·근거 문서 이름만 저장되고 답변 내용(회사 문서 내용)은 들어가지 않습니다.
     원인 분석에 답변이 필요하면 [결과표에 답변 내용도 넣기]를 체크합니다.


6. 문제가 생기면
----------------
- "Ollama에 연결할 수 없습니다": 작업 표시줄 오른쪽 아래에 Ollama(라마 그림)가 있는지 확인하고,
  없으면 '설치.bat'을 다시 실행합니다.
- 화면이 안 열림: 검은 창이 켜져 있는지 확인하고 http://127.0.0.1:8765 를 직접 엽니다.
- 답이 느림: 그래픽카드가 없거나 작은 PC에서는 답 하나에 수십 초가 걸릴 수 있습니다.
  설치할 때 이런 PC에서는 '추론 모드'(config.json의 think)를 자동으로 끕니다.
  추론 모드를 켜면(true) 예외 조건을 더 잘 읽지만, 그래픽카드가 없으면 답 하나에 몇 분 걸릴 수 있습니다.
- 그 밖의 문제는 검은 창에 나온 문장을 캡처해 크몽 메시지로 보내 주세요.


7. 알아 두실 점
---------------
- AI는 틀릴 수 있습니다. 중요한 내용은 근거 문서를 꼭 확인하세요.
- 문서에 없는 내용은 "찾지 못했습니다"라고 답하도록 설정되어 있습니다.
- 사용 모델: 답변 qwen3(Apache-2.0), 문서 검색 bge-m3(MIT). 상업 사용이 가능한 라이선스입니다.
