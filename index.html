첫 수입을 위한 4주 계획

아래 금액은 제안용 예시이며 실제 수요·작업 범위에 따라 달라집니다. 수익을 보장하지 않습니다.

1주 · 작은 서비스 하나

정적 소개 페이지, CSV 정리 자동화, 문서 사이트 중 할 수 있는 것 하나를 고르세요. 샘플 1개를 GitHub에 올리고 작업 범위와 납기를 적으세요.

2주 · 고객 문제 확인

주변 가게·동아리·프리랜서에게 필요한 작업을 직접 물어보세요. 소개 페이지 1개 5만 원처럼 명확한 결과물로 제안하고, 비용·수정 횟수를 합의하세요.

3주 · 납품과 수금

작업물을 검토받고 합의한 범위로 납품하세요. 실제 받은 금액을 기록하고, 허락받은 결과물과 후기를 포트폴리오에 추가하세요.

4주 · 반복 가능한 작업

비슷한 작업을 템플릿으로 만들고 두 번째 의뢰를 제안하세요. 예: 5만 원 작업 2건 = 매출 10만 원. 비용·수수료·세금은 별도입니다.

GitHub에서 참고할 프로젝트

아래는 알려진 프로젝트입니다. 현재 상태와 라이선스는 각 저장소에서 확인하세요. 코드를 재사용할 때는 라이선스·저작권 고지 의무를 따라야 합니다.

  • Astro — 가게 소개·포트폴리오 사이트 제작의 기반
  • MkDocs — 팀 매뉴얼·사용 설명서 사이트 구축
  • Datasette — 공개 데이터 탐색 도구와 데이터 정리 서비스 참고

GitHub는 샘플·코드·작업 이력을 보여주는 포트폴리오로 활용하세요. 첫 달에는 다운로드나 후원보다 구체적인 고객 작업 한 건을 목표로 삼는 편이 현실적입니다.
