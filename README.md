## 실행

Python 3만 있으면 됩니다. 외부 패키지나 API 키는 필요 없습니다.

```sh
cd /workspace/review-helper
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 실행한 서버의 페이지를 여세요. 수입 기록은 해당 브라우저의 localStorage에 저장됩니다. 월별 조회, 목표 달성률, 기록 삭제, JSON 내보내기를 지원합니다. 내보낸 파일을 가져오는 기능은 아직 없습니다. 공용 기기에서는 개인 수입 정보를 남기지 마세요.

## 수익화 방향

첫 달 기본 목표 예시: 5만 원의 작은 웹 제작 작업 2건. 실제 수익은 고객 확보와 납품 여부에 달려 있습니다. 매출에서 수수료·비용·해당 세금을 별도로 고려하세요.

1. 소개 페이지, 문서 사이트, 데이터 정리 중 가능한 작업 하나를 선택합니다.
2. GitHub에 샘플과 작업 범위·납기·수정 횟수를 공개합니다.
3. 주변 잠재 고객의 문제를 확인하고 작은 고정 범위로 견적을 제안합니다.
4. 합의한 결과물을 납품하고 수금한 뒤, 허락받은 후기와 사례를 정리합니다.

앱 자체의 유료화는 사용자 수요를 확인한 후 검토하세요. 현재 앱은 로그인·결제·서버 저장을 제공하지 않습니다.
